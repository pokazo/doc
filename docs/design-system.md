# Дизайн-система Pokazo

> Проверено: 2026-10-04 · источники: референсы Slidy / SimpleSlide / Gamma (таймаут fetch), бренд Pokazo · не Figma-файл, токены для кода

## Вердикт

Не клонировать фиолетовый SaaS и не клонировать Slidy. Метафора — **сцена/показ**: бумага слайда 16:9, тёплый свет, один терракотовый акцент. Кириллица first-class (Unbounded + Golos).

**С чего начать:** CSS variables в `apps/web/src/styles/tokens.css`, компоненты ниже — только то, что нужно лендингу и auth.

## Принципы

| # | Правило |
|---|---------|
| 1 | Один экран — одно действие (тема / вход / показ). |
| 2 | Слайд всегда 16:9, скругление 12px, тень как карточка на столе, не glassmorphism. |
| 3 | CTA один на экране, терракота. Вторичное — контур. |
| 4 | Без нейро-градиентов и «AI particles». |
| 5 | Интерфейс на «ты», коротко. H1 из Wordstat, не «революционная платформа». |

## Токены цвета

Имена в коде: `--pk-*`. Контраст текста на бумаге ≥ 4.5.

| Токен | Hex | Роль |
|-------|-----|------|
| `--pk-paper` | `#F4EFE6` | фон страницы |
| `--pk-paper-2` | `#EBE4D8` | полосы, footer |
| `--pk-ink` | `#1C1814` | текст |
| `--pk-ink-muted` | `#5C534A` | вторичный текст |
| `--pk-line` | `#D4CBBC` | бордеры |
| `--pk-spot` | `#C45C26` | CTA, ссылки, фокус |
| `--pk-spot-hover` | `#A34A1C` | hover CTA |
| `--pk-spot-soft` | `#F3E0D4` | chip, фон кнопки Яндекс-не |
| `--pk-stage` | `#1C1814` | тёмный хедер/плеер chrome |
| `--pk-on-stage` | `#F4EFE6` | текст на stage |
| `--pk-danger` | `#B42318` | ошибки форм |
| `--pk-ok` | `#2F6B4F` | успех |

Яндекс-кнопка: официальные цвета виджета Яндекс ID, **не** перекрашивать в `--pk-spot`.

## Типографика

| Роль | Шрифт | Вес | Размер / line |
|------|--------|-----|----------------|
| Display / логотип | [Unbounded](https://fonts.google.com/specimen/Unbounded) | 600 | 40–56 / 1.1 |
| H1 лендинг | Unbounded | 600 | clamp(32px, 5vw, 52px) / 1.15 |
| H2 секций | Unbounded | 500 | 24–28 / 1.25 |
| UI / body | [Golos Text](https://fonts.google.com/specimen/Golos+Text) | 400/500 | 16–18 / 1.5 |
| Кнопка | Golos Text | 500 | 16 |
| Caption | Golos Text | 400 | 13 / 1.4, `--pk-ink-muted` |

Подключение: `fontsource` или Google Fonts, `html { font-family: "Golos Text", system-ui, sans-serif }`. Цифры в CTA — tabular если будут тарифы.

## Сетка и ритм

- Контент max-width **1120px**, padding 20px.
- Вертикальный ритм секций: 80px desktop / 48px mobile.
- Радиусы: `--pk-r-sm: 8px` (инпуты), `--pk-r-md: 12px` (карточка слайда), `--pk-r-pill: 999px` (chip аудитории).
- Фокус: 2px outline `--pk-spot`, offset 2px. Не `outline: none`.

## Компоненты MVP

| Компонент | Поведение |
|-----------|-----------|
| `PkHeader` | логотип «Показо» (Unbounded), справа «Войти» / аватар |
| `PkButton` | `primary` / `ghost` / `yandex`; высота 48px |
| `PkInput` | тема презентации, 56px, placeholder «Тема доклада…» |
| `PkSlideFrame` | обёртка 16:9, фон белый, бордер `--pk-line` |
| `PkAuthCard` | бумага, max 400px, заголовок, Яндекс, разделитель «или», email |
| `PkStatus` | queued / generating / building — одна строка, без скелетон-ада |

Состояния кнопок: default, hover, active, disabled (opacity 0.45), loading (текст «Создаём…», не спиннер-радуга).

## Лендинг (каркас)

```
[ Header ]
[ Hero: H1 + поле темы + Создать ]
[ PkSlideFrame — статичный превью 3 слайда ]
[ 3 шага ]
[ Для кого: школа / вуз / работа ]
[ FAQ ]
[ Footer: оферта, персональные данные ]
```

Mobile: поле темы на всю ширину, CTA под ним, превью слайда с горизонтальным скроллом точек.

## Чего нет в v1 дизайн-системы

Тёмная тема, иконочный набор свой (только SVG логотипа и Яндекс), таблица тарифов, модалки редактора, toast-stack.

## Не брать / оговорки

- Inter как у Slidy — нет, латиница-first.
- Tailwind CDN как gamma-app.ru — нет; утилиты ок, токены свои.
- «Нейросеть» в логотипе — нет, только в H1 для SEO.
