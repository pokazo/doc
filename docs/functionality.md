# Функционал Pokazo (MVP: генерация)

> Проверено: 2026-10-04 · источники: сессия + [architecture.md](./architecture.md) · бренд: Pokazo / pokazo.ru

## Вердикт

Пользователь вводит тему (и необязательно детали) → получает **готовую презентацию в браузере** (плеер Slidev). Править слайды руками в MVP **нельзя**. Скачивание: веб-ссылка обязательно; PDF — если успеваем; PPTX не обещать как редактируемый файл.

**С чего начать:** один сценарий «создать с нуля по теме» на русском.

## Персона и работа

| Кто | Задача | Успех |
|-----|--------|--------|
| Школа / вуз / офис (RU) | «Сделай презентацию про …» | За минуты открывается колода, можно листать и шарить ссылку |

Спрос (якорь): «нейросеть для презентаций» — [wordstat-top-queries.md](./wordstat-top-queries.md).

## Сценарий MVP (единственный)

1. Открыть pokazo.ru (или app).
2. Поле: тема. Опции: число слайдов (по умолчанию 8–12), аудитория (школа / вуз / работа), язык (ru default).
3. Кнопка «Создать». Статус: очередь → генерация → сборка.
4. Редирект на `/p/:id` — полноэкранный показ Slidev.
5. Кнопки: «Смотреть», «Скопировать ссылку». Опционально «PDF».

Нет: чат на 20 сообщений, импорт PPTX, «улучши слайд 3», конструктор блоков.

## Контракт входа (генерация)

| Поле | Обязательно | Заметки |
|------|-------------|---------|
| `topic` | да | 5–500 символов |
| `locale` | нет | `ru` |
| `slideCount` | нет | clamp 6–16 |
| `audience` | нет | `school` \| `university` \| `work` |
| `theme` | нет | id пресета Slidev |

Выход: `deckId`, `status`, `viewUrl`. Ошибки: модерация темы, таймаут LLM, `slidev build` fail → «не собралось, повторите» + не отдавать битый dist.

## Правила содержимого слайдов

Зашиваются в агент (официальный skill + whitelist), пользователь их не настраивает:

- Один тезис на слайд, без простыни.
- Только разрешённые layout Slidev (см. архитектуру).
- Заголовок ≤ ~8 слов; буллеты ≤ 5 на слайд.
- Код — только если тема техническая.
- Язык колоды = `locale`.

Второй проход (если время): skill «улучшить» / MCP reorder. Не отдельная кнопка в UI.

## Состояния UI

| Статус | Что видит пользователь |
|--------|-------------------------|
| `queued` | «В очереди» |
| `generating` | «Пишем слайды» |
| `building` | «Собираем показ» |
| `ready` | Плеер |
| `failed` | Ошибка + повторить |

Идемпотентный «повторить» с тем же `input.json`.

## Нефункционал с точки зрения продукта

| Требование | MVP |
|------------|-----|
| Время до ready | целевое &lt; 2 мин на 10 слайдов (зависит от модели) |
| Показ без нашего UI chrome | чистый Slidev presenter |
| Мобильный | лендинг+форма; плеер — как получится у Slidev |
| Пустые/оскорбительные темы | отказ |

## Критерии готовности MVP

- С темы «Введение в фотосинтез, 8 слайдов, школа» собирается колода, ссылка открывается в инкогнито.
- `slides.md` лежит в артефакте, сборка воспроизводима тем же md.
- Нет экрана редактора.
- В маркетинге нет обещания «скачай и правь в PowerPoint».

## Не брать / оговорки

- Это не паритет Gamma/Slidy: у них редактор и выгрузка PPTX — ядро. У нас сознательно **только генерация+веб**.
- Готовые агенты — промпты и MCP на сервере, не «установите Claude Code».
