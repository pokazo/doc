# Лендинг pokazo.ru

> Проверено: 2026-10-04 · источники: [slidy.ai](https://slidy.ai/), [simpleslide.ru](https://simpleslide.ru/), Wordstat, [design-system.md](./design-system.md)

## Вердикт

Одна страница. Герой — **поле темы + «Создать»**, не каталог шаблонов и не супер-апп «видео+фото+реферат». H1 = спрос Wordstat. Вход через шапку, генерация после сессии (тема сохраняется в `?topic=`).

**С чего начать:** сверстать hero + header по [design-system.md](./design-system.md).

## Референсы: что взять / отрезать

| Сервис | Взять | Не брать |
|--------|--------|----------|
| **Slidy** | Русский, учёба/работа в копирайте; «без VPN»; CTA сразу; сравнение «минуты vs часы» | Комбайн презентации+видео+фото; «нам доверяют миллионы»; отзывы-простыня; 1₽ подписка в FAQ героя |
| **SimpleSlide** | H1 «нейросеть для презентаций»; вход по теме; аудитории студент/учитель/бизнес | «без регистрации» как главное (у нас LLM надо закрыть аккаунтом); обещание PPTX в первом экране; 30 шаблонов |
| **Gamma** | Поле ввода как главный объект; веб-показ как результат | Английский first; карточки-документ; фиолетовый SaaS |

## IA и маршруты

| URL | Кто видит |
|-----|-----------|
| `/` | лендинг |
| `/login` | карточка входа (Яндекс + email) |
| `/app` | форма генерации (если уже в сессии; иначе → login) |
| `/p/:id` | плеер Slidev (позже) |

С `/` кнопка «Создать»: если нет cookie → `/login?next=/app&topic=…`. Если есть → `/app` с темой.

## Копирайт (канон)

**H1:** Нейросеть для презентаций  
**H1 visually (опционально вторая строка Unbounded):** Показо  
**Подзаголовок:** Тема — слайды в браузере за пару минут. Ссылку можно отправить.  
**Placeholder:** Например: «Фотосинтез, 8 слайдов, 8 класс»  
**CTA:** Создать  
**Шапка:** Войти  
**Три шага:** 1. Тема 2. ИИ собирает слайды 3. Смотрите по ссылке  
**Для кого:** Школа · Вуз · Работа  
**FAQ:** Нужен ли VPN? Нет. Можно без PowerPoint? Да, показ в браузере. Когда файл PPTX? Позже, не обещаем в MVP.  
**Юр.:** оферта, политика ПДн (заглушки-страницы).

Не писать: «лучше Gamma», «98% как PowerPoint», «бесплатно навсегда».

Description: `Создайте презентацию по теме онлайн. Русский язык, без VPN.`  
H1 один. Не пихать «гамма» в title.

## Метрика (заложить data-атрибуты)

`data-pk="cta-create"`, `data-pk="cta-login"`, `data-pk="auth-yandex"`. Счётчик Яндекс.Метрики — отдельной задачей, не в вёрстке героя.

## Не брать / оговорки

Лендинг не содержит живой `slidev dev`. Превью — статичные PNG/SVG трёх слайдов в `PkSlideFrame`.
